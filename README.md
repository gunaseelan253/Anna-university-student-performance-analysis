# Anna University Students Performance Analysis

## 📌 Project Overview

A data analytics project focused on analyzing **Anna University student performance and academic factors** using Python and SQL.

The project analyzes **500 student records across 16 attributes** to identify patterns in academic performance, attendance, backlogs, faculty ratings, student satisfaction, skill training, and internship status.

The analysis follows an end-to-end workflow covering **data cleaning, exploratory data analysis, visualization, correlation analysis, and SQL-based insights**.

---

## 🎯 Objectives

* Analyze overall student academic performance
* Identify department-wise performance patterns
* Analyze attendance and backlog trends
* Study faculty and lab facility ratings
* Analyze student satisfaction
* Examine internship status
* Identify relationships between key performance factors
* Perform structured SQL analysis on student data

## 📊 Key Insights

* **Total Students:** 500
* **Average Mark:** 88.71
* **Average Attendance:** 81.32%
* **Total Backlogs:** 154
* **Average Student Satisfaction:** 3.55 / 5

Department-wise academic performance and attendance were also analyzed to identify variations across departments.
